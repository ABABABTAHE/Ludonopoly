1. Install Visual Studio Code (VS Code) and the Extension Pack for Java from the VS Code Extensions Marketplace.
2. Setting Up the Project
   1. Open VS Code.
   2. Navigate to File > Open Folder and select the folder containing the game project files.
   3. Ensure that all required Java files are in the project folder.
3. How to Run the Monopoly Game
   1. Open the MonopolyInitGUI.java file in the VS Code editor.
   2. Press Run Java (you'll see this option above the main method or in the top right corner of VS Code).
   3. The Monopoly game will start running in the integrated terminal or a new Java console window.
4. How to Run the Snake & Ladder Game
   1. Open the SnakeLadderGame.java file in the VS Code editor.
   2. Press Run Code.
   3. The Snake & Ladder game will start running in the integrated terminal.
